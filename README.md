# Memorial DAD - UFV

Este projeto é um memorial histórico para o Departamento de Administração e Contabilidade da UFV.

## Créditos

- **Realização:** Departamento de Administração e Contabilidade (DAD) — Universidade Federal de Viçosa
- **Design e desenvolvimento:** [Eduardo Jesus](https://www.linkedin.com/in/eduarrdojesus)

## Documentação

| Arquivo | Para quê |
|---|---|
| [PAINEL-ADMIN.md](PAINEL-ADMIN.md) | Uso e configuração do painel administrativo (`/admin`) na Vercel |
| [SOLICITACAO-DTI.md](SOLICITACAO-DTI.md) | Pedido de hospedagem enviado à DTI da UFV |
| [HOSPEDAGEM-DTI.md](HOSPEDAGEM-DTI.md) | Instalação e atualização do site no servidor da UFV |
| [APRESENTACAO.md](APRESENTACAO.md) | Notas da apresentação do Memorial |

## Comandos

| Comando | O que faz |
|---|---|
| `npm run dev` | Abre o site no computador para desenvolvimento |
| `npm run build` | Gera a versão da Vercel em `dist/` |
| `npm run build:dti` | Gera a versão do servidor da UFV em `dist-dti/` |
